# 1550 nm MNIST D2NN

本目录包含依据 Lin 等 2018 年论文及补充材料重新设计的 MNIST 仿真代码。
**本次只完成阅读、编写与静态审阅，未安装依赖、下载数据、运行代码、训练或测试。**

重点先读[1550 nm实验参数选择依据](H:/PROJECT/study/simulation_d2nn/1550_d2nn/PARAMETER_DECISIONS.md)。指定参考脚本虽然已经设置1550 nm，但默认400 µm单元、80 mm口径和零输入距离需要重新设计；本目录并非只替换波长。

- [完整复现方案](H:/PROJECT/study/simulation_d2nn/1550_d2nn/REPRODUCTION_PLAN.md)：论文参数对照、物理模型、几何、加工与后续验收计划。
- [完整主程序](H:/PROJECT/study/simulation_d2nn/1550_d2nn/train_mnist_1550.py)：带注释的独立单入口，集成训练、验证、测试、出图、加工版图、容差与数值收敛诊断。
- [依赖说明](H:/PROJECT/study/simulation_d2nn/1550_d2nn/requirements.txt)：Python 3.10 及以上，NumPy、Matplotlib、PyTorch。GPU版PyTorch需要与用户的CUDA环境匹配。

默认结构为五层，每层200×200个20 µm单元，有效口径4 mm；全部空气参考间隔40 mm，包含非零输入传播和每片0.5 mm基板内传播。输入到输出的名义长度242.5 mm。默认采用熔石英八级完整周期相位，最大浮雕高度约3.05 µm，三次二值刻蚀。相位面、空气段与基板的距离定义见完整方案第4节。

准备依赖后，未来在本目录只需执行一次下面的命令，即可完成整个流程；**本次未执行**：

```powershell
python .\train_mnist_1550.py --download
```

`--download`允许下载缺失的官方MNIST，并核对压缩文件校验值。若不需要联网，可将四个官方IDX或IDX.gz文件放入本目录`data/MNIST/raw`后省略该选项。没有本地数据目录时，程序也允许只读复用原项目`data/MNIST/raw`。所有新下载和结果文件默认均位于本目录。

默认使用55,000张训练、5,000张验证和10,000张测试，先连续训练30轮，再量化微调10轮。验证集从官方训练集按每类500张抽取并保存索引；测试集用于最终评价。单次运行自动建立`runs/时间戳/`，保存配置、日志、检查点、逐图预测、混淆矩阵、能量与相位图、误差和收敛结果、相位/高度CSV、DOE刻蚀SVG及50张不按分类成功与否筛选的输入掩模SVG。

参考用户指定训练脚本，将Adam初始学习率设为0.005，量化阶段设为0.001，相位raw参数初始化标准差0.7；默认joint损失权重为0.05/0.05/0.05，也可用`--loss-mode baseline`作原脚本的baseline目标对照。优化参数不按波长比缩放，这些设置仍是待验证起点。

主要可调参数都在同一脚本的`Config`中，也可在同一运行命令后添加选项：

| 选项 | 默认值 | 含义 |
|---|---:|---|
| `--input-gap-mm` | 40 | 输入面到第一片前表面的空气距离，必须大于0 |
| `--layer-gap-mm` | 40 | 本片出口参考面到下一片前表面的空气距离 |
| `--output-gap-mm` | 40 | 末片出口参考面到探测面的空气距离 |
| `--phase-range-pi` | 2 | 设为1可研究原文Methods所述π限幅对照 |
| `--phase-levels` | 8 | 2的幂；4级可减少至两次刻蚀，但性能需重新训练 |
| `--batch-size` | 8 | 训练批量；显存不足时首先调小 |
| `--learning-rate` | 0.005 | 连续训练初始学习率；QAT默认乘0.2 |
| `--loss-mode` | joint | 复用参考脚本的效率导向目标，可选baseline |
| `--eval-batch-size` | 2 | 测试及更细网格评估批量 |
| `--oversample` / `--padding` | 4 / 2 | 默认1600×1600传播网格；更改时也应增大对应收敛参考参数 |
| `--convergence-oversample` / `--convergence-padding` | 6 / 3 | 固定相位的采样和窗口参考设置 |
| `--surface-reflectance` | 0.005 | 每面功率反射率，AR设计假定，实际需标定 |

输入112×112个制造像元对应2.24 mm区域，阈值0.5、探测区中心、学习率和损失权重都是明确的工程选择。论文91.75%是原THz系统的数值结果，本设计准确率未知。

加工文件是待审设计交换文件。数值收敛未通过时不应据此投产；通过小样本筛查也仍需加工平台确认刻蚀、套刻、减反膜与材料数据。普通桌面3D打印不能替代本方案的微米浮雕工艺。
